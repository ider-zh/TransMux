# 术语管理改版验收（2026-09-18）

## 已实现

- 风格、术语上下分行，术语全宽并可展开到近全屏；专业术语、翻译对照、人名三个标签页，支持搜索、状态筛选和证据展开。
- 自动收录需要明确一致性需求、理由和适用语境，并检查原文证据。普通定义不构成收录理由；简单词也不被一律排除。
- 同词不同语境可并存。冲突成为待确认候选，用户指定内容不会被自动覆盖。只将已生效条目放入常规任务提示词快照，删除/停用决定有保护。
- 人名单独存入 `people.json`，带标准写法、已确认别名、来源及状态。不明身份保留原文，候选不作为强制规则。现有翻译审校同时检查人名正文和元数据，没有增加日常调用步骤。
- 支持粘贴表格、XLSX/CSV/TSV 导入、模板下载、列匹配、可编辑预览。重复与冲突默认跳过，明确选择替换才覆盖；保存检查预览版本。
- 旧条目重新筛选是独立任务，先生成建议；用户勾选、编辑并确认后应用。用户指定内容不参与自动筛选，归入人名的候选先待确认，旧条目停用并保留历史。

- 新版术语专项共 10 项通过，含普通定义排除、作用域/冲突、未知人名、CSV/XLSX、公式拒绝、导入冲突、历史与项目隔离、筛选版本检查、提示词状态隔离、写入失败回滚、人名元数据审校等路径（部分测试覆盖多条路径）。
- 最后一次保存语言规则调整后，术语、语言和历史联合复验 34 项通过。
- 原有浏览器全流程通过；新术语浏览器验收通过：全宽布局、展开、筛选预览/应用、粘贴导入、冲突默认跳过、人名确认、刷新持久化、桌面与手机。
- Ruff、JavaScript 语法检查通过。

## 边界

语义收录判断仍依赖 Agent，程序能验证结构、字段、语言和引用，但不能保证每个理由都准确。新跨语言人名对应保守进入待确认，未接入外部人物身份数据库。升级只创建独立人名配置并兼容旧术语；旧条目需用户主动重新筛选，不会自动删除。
