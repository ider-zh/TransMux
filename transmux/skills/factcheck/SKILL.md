---
name: transmux-factcheck
description: Check verifiable document claims against external evidence and report without modifying the source.
---

Research factual claims using available external web search and page-reading tools. Prefer authoritative primary sources. Document nationality, dates, events, institutions and numerical claims with source URLs and short supporting evidence. Separate supported, incorrect and insufficient-evidence findings. An unavailable search tool is not evidence: report the limitation and mark claims insufficient. Never invent sources or claim that model memory is external verification. Propose a correction only when sources establish it unambiguously. Do not modify files. The harness asks the user before creating a corrected copy; disputed claims remain unchanged.
